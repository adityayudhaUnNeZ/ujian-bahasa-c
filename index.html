Cakupan Materi Ujian

Bahasa C
  • 1 Tipe Data Primitif & Variabel: int, float, char, bool, serta 5 aturan wajib penamaan variabel.
  • 2 Operator Pemrograman: Aritmetika (+ - * / %), Relasional (== != > < >= <=), dan Logika (&& || !).
  • 3 Sintaks & I/O Bahasa C: Struktur #include <stdio.h>, scanf("%d", &x), dan printf().
  • 4 Tebak Kasus Visual & Debugging: Bedah Flowchart, Tabel Penelusuran Manual (Tracing), serta diagnosis Syntax Error, Runtime Error, dan Logical Error.

Ringkasan Kilat Sintaks C & Debugging

• Format Specifier C: %d untuk int, %f / %.2f untuk float, %c untuk char. Jangan lupa tanda & pada scanf("%d", &x);.

• Syntax Error: Melanggar tata bahasa C (lupa ;, salah ketik prinft, kurung {} kurang). Terdeteksi langsung oleh compiler.

• Runtime Error: Gagal saat program sedang berjalan (pembagian dengan 0, lupa & pada scanf hingga crash).

• Logical Error: Program berjalan lancar tanpa pesan eror, tetapi hasil keluaran (Actual Output) salah karena keliru rumus atau tanda relasional/logika.
