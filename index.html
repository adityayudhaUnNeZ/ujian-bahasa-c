Ringkasan Kilat Sintaks C & Debugging

• Format Specifier C: %d untuk int, %f / %.2f untuk float, %c untuk char. Jangan lupa tanda & pada scanf("%d", &x);.

• Syntax Error: Melanggar tata bahasa C (lupa ;, salah ketik prinft, kurung {} kurang). Terdeteksi langsung oleh compiler.

• Runtime Error: Gagal saat program sedang berjalan (pembagian dengan 0, lupa & pada scanf hingga crash).

• Logical Error: Program berjalan lancar tanpa pesan eror, tetapi hasil keluaran (Actual Output) salah karena keliru rumus atau tanda relasional/logika.

Perhatikan operasi aritmetika pada potongan kode Bahasa C di atas! Berapakah luaran (output) yang ditampilkan oleh perintah printf pada baris ke-3?

A 16 dan 1 ✓ Kunci Jawaban
B 16 dan 16
C 60 dan 4
D 15 dan 0

Kode Soal Q4 (Urutan Standar #4) Kasus Visual Kode C
1 | int harga = 50000;
2 | float diskon = 0.2;
3 | bool member = true;
4 | int potong_harga = harga * diskon;
5 | int total_bayar = harga - potong_harga;
6 | bool dapat_promo = (total_bayar <= 40000) && member;
7 | printf("Total: %d | Promo: %d", total_bayar, dapat_promo);

Berdasarkan kode program Bahasa C pada materi Sintaks 3 Bahasa di atas, berapakah nilai yang tampil di layar saat program dijalankan?

A Total: 10000 | Promo: 0
B Total: 40000 | Promo: 1 ✓ Kunci Jawaban
C Total: 40000 | Promo: 0
D Total: 50000 | Promo: 1
Pembahasan Guru: potong_harga = 50000 * 0.2 = 10000. total_bayar = 50000 - 10000 = 40000. Karena (40000 <= 40000) bernilai True DAN member bernilai True, maka dapat_promo bernilai True (ditampilkan sebagai 1 oleh %d di C).

Perhatikan visualisasi Flowchart Skenario 1 (Kasir Diskon Bioskop dengan diskon 30% + 20% untuk usia < 12 tahun) di atas! Dengan data uji usia = 10, berapakah nilai total_bayar yang dicetak oleh program?

A Rp 50.000

Perhatikan Flowchart Skenario 2 di atas! Jika diuji dengan nilai_teori = 80 dan nilai_praktik = 70, bagaimanakah hasil evaluasi operator logika && dan luaran (Expected Output) yang dihasilkan?

A True && True -> Menghasilkan output "LULUS"
B True && False -> Menghasilkan output "LULUS"
C True && False -> Menghasilkan output "REMEDIAL" ✓ Kunci Jawaban
D False && False -> Menghasilkan output "REMEDIAL"
Pembahasan Guru: Evaluasi kondisi pertama: 80 >= 75 bernilai True. Kondisi kedua: 70 >= 75 bernilai False. Karena menggunakan operator AND (&&) yang hanya bernilai True jika SEMUA kondisi benar, maka True && False menghasilkan False ("REMEDIAL").
Kode Soal Q8 (Urutan Standar #8) Debugging: Syntax Error
1 | #include <stdio.h>
2 | int main() {
3 | float suhu_tubuh = 38.2
4 | if (suhu_tubuh > 37.5) {
5 | printf("Status: DEMAM\n");
6 | }
7 | return 0;
8 | }
[Compiler Output] main.c:4:5: error: expected ',' or ';' before 'if'

Saat perwakilan Tester mengetik kode Skenario 4 di laptop guru, program gagal dikompilasi dan memunculkan pesan error seperti pada layar di atas. Termasuk kategori galat apakah ini dan bagaimana perbaikannya?

A Logical Error — Perbaikannya dengan mengganti tanda > menjadi < pada baris ke-4.
B Syntax Error — Perbaikannya dengan menambahkan tanda titik koma (;) di akhir baris ke-3. ✓ Kunci Jawaban
C Runtime Error — Perbaikannya dengan mengganti tipe data float menjadi char pada baris ke-3.
D Logical Error — Perbaikannya dengan menghapus #include pada baris ke-1.
Pembahasan Guru: Lupa menuliskan titik koma (;) di akhir pernyataan baris ke-3 melanggar aturan tata bahasa (sintaksis) Bahasa C sehingga langsung terdeteksi oleh compiler sebagai Syntax Error.
Kode Soal Q9 (Urutan Standar #9) Debugging: Runtime Error
1 | #include <stdio.h>
2 | int main() {
3 | int lama_parkir;
4 | printf("Masukkan jam parkir: ");
5 | scanf("%d", lama_parkir);
6 | printf("Jam: %d\n", lama_parkir);
7 | return 0;
8 | }
Masukkan jam parkir: 3
[Process exited: Segmentation fault (core dumped) saat program sedang berjalan]

Program di atas berhasil dikompilasi, tetapi begitu pengguna mengetik angka 3 dan menekan Enter, program langsung berhenti mendadak (crash). Berdasarkan materi Debugging, termasuk kategori galat apakah kasus ini?

A Runtime Error — Karena terjadi ketika program sedang dijalankan akibat lupa menulis simbol & pada scanf("%d", &lama_parkir); ✓ Kunci Jawaban
B Syntax Error — Karena variabel lama_parkir tidak boleh menggunakan huruf kecil.
C Logical Error — Karena program berhasil mencetak hasil akhir namun angkanya keliru.
D Hardware Error — Karena keyboard laptop guru tidak memiliki tombol angka 3.
Pembahasan Guru: Kesalahan yang menyebabkan program berhenti mendadak (crash) ketika sedang dieksekusi disebut Runtime Error. Pada bahasa C, lupa menulis & pada scanf membuat program menulis ke alamat memori yang tidak valid.
Kode Soal Q10 (Urutan Standar #10) Debugging: Logical Error
// Skenario 3: Parkir 1 jam pertama Rp 5.000, tiap jam berikutnya Rp 3.000/jam
1 | int lama_parkir = 3;
2 | int total_tarif = 5000;
3 | if (lama_parkir > 1) {
4 | total_tarif = total_tarif + (lama_parkir * 3000);
5 | }
6 | printf("Total Parkir: Rp %d\n", total_tarif);
Expected Output: Total Parkir: Rp 11000 | Actual Output di Laptop: Total Parkir: Rp 14000

Program Skenario 3 di atas berjalan lancar tanpa pesan error, tetapi menghasilkan Actual Output Rp 14000 (seharusnya Rp 11000 untuk 3 jam parkir). Jenis galat dan kode perbaikan (Fix Code) baris ke-4 yang tepat adalah...

A Syntax Error — Ubah baris 4 menjadi: total_tarif = 5000 - 3000;
B Logical Error — Ubah baris 4 menjadi: total_tarif = total_tarif + ((lama_parkir - 1) * 3000); ✓ Kunci Jawaban
C Runtime Error — Ubah baris 4 menjadi: total_tarif = lama_parkir / 0;
D Syntax Error — Hapus kurung kurawal pada baris ke-3 dan ke-5.
Pembahasan Guru: Program berjalan tanpa eror namun hasilnya tidak sesuai harapan (Expected Output != Actual Output), sehingga termasuk Logical Error. Karena 1 jam pertama sudah dihitung Rp 5.000, maka jam tambahan adalah (lama_parkir - 1) * 3000.

Kode Soal Q12 (Urutan Standar #12) Debugging Operator Logika
// Skenario 6: Boleh naik Roller Coaster jika tinggi minimal 140 cm DAN usia minimal 10 tahun
1 | int tinggi_badan = 145;
2 | int usia = 9;
3 | if (tinggi_badan >= 140 || usia >= 10) {
4 | printf("Status: BOLEH NAIK\n");
5 | } else {
6 | printf("Status: TIDAK BOLEH NAIK\n");
7 | }

Dengan data uji tinggi_badan = 145 dan usia = 9, seharusnya output adalah "TIDAK BOLEH NAIK". Namun kode di atas justru mencetak "BOLEH NAIK". Apa penyebab kesalahan logika pada baris ke-3?

A Karena penulis kode menggunakan operator OR (||) yang bernilai True jika salah satu syarat terpenuhi, seharusnya menggunakan operator AND (&&). ✓ Kunci Jawaban
B Karena penulis kode menggunakan tanda >=, seharusnya menggunakan tanda !=.
C Karena nilai tinggi_badan = 145 lebih kecil dari 140.
D Karena tipe data int tidak bisa dibandingkan menggunakan operator relasional.
Pembahasan Guru: Operator || (OR) menghasilkan True jika salah satu kondisi benar (145 >= 140 bernilai True). Karena aturan wahana mewajibkan KEDUA syarat terpenuhi sekaligus, maka wajib menggunakan operator && (AND).
Kode Soal Q13 (Urutan Standar #13) Debugging Format Output
1 | float total_bayar = 40000.50;
2 | printf("Total Bayar: Rp %d\n", total_bayar);

Ketika kode di atas dijalankan, nilai total_bayar yang bertipe float tidak tampil sebagai 40000.50 melainkan angka acak yang keliru. Bagaimana cara memperbaiki baris ke-2?

A Mengganti format specifier %d menjadi %.2f karena variabel total_bayar bertipe float (angka desimal). ✓ Kunci Jawaban
B Mengganti perintah printf menjadi scanf.
C Menghapus tanda kutip dua pada teks di dalam printf.
D Menambahkan simbol && di depan variabel total_bayar.
Pembahasan Guru: Format specifier %d hanya diperuntukkan bagi bilangan bulat (int). Untuk menampilkan nilai bertipe float atau double dengan dua angka di belakang koma, gunakan %.2f.
Kode Soal Q14 (Urutan Standar #14) Komparasi Sintaks 3 Bahasa
Kartu Kode X harga = 50000
member = True
print(f"Rp {harga}")
Kartu Kode Y int harga = 50000;
bool member = true;
printf("Rp %d", harga);
Kartu Kode Z int harga = 50000;
boolean member = true;

Perhatikan ketiga Kartu Kode di atas! Berdasarkan materi Sintaks 3 Bahasa, manakah urutan nama bahasa pemrograman yang tepat untuk Kartu X, Kartu Y, dan Kartu Z?

A X = C, Y = Python, Z = Java
B X = Python, Y = C, Z = Java ✓ Kunci Jawaban
C X = Java, Y = C, Z = Python
D X = Python, Y = Java, Z = C
Pembahasan Guru: Kartu X adalah Python (tanpa deklarasi tipe data, tanpa titik koma, menggunakan print(f"...")), Kartu Y adalah Bahasa C (menggunakan bool dan printf), sedangkan Kartu Z adalah Java (menggunakan boolean dan System.out.println).
Kode Soal Q15 (Urutan Standar #15) Debugging Kondisi Percabangan
1 | int status_member = 0; // 0 = Bukan Member, 1 = Member
2 | if (status_member = 1) {
3 | printf("Selamat, Anda Dapat Diskon Member!\n");
4 | } else {
5 | printf("Harga Normal\n");
6 | }

Walaupun status_member bernilai 0 (Bukan Member), program di atas selalu mencetak "Selamat, Anda Dapat Diskon Member!". Apa penyebab bug pada baris ke-2 dan bagaimana memperbaikinya?

A Baris ke-2 menggunakan operator pengisian nilai (=) bukan operator relasional sama dengan (==), sehingga status_member diisi menjadi 1 (True). Perbaikannya: if (status_member == 1). ✓ Kunci Jawaban
B Baris ke-2 menggunakan angka 1, seharusnya menggunakan angka 100.
C Tipe data int tidak bisa digunakan di dalam kurung if pada Bahasa C.
D Perintah printf pada baris ke-3 harus diganti menjadi scanf.
Pembahasan Guru: Dalam Bahasa C, satu tanda sama dengan (=) adalah assignment (mengubah nilai variabel menjadi 1 yang dievaluasi sebagai True), sedangkan untuk membandingkan kesamaan dua nilai wajib menggunakan dua tanda sama dengan (==).
